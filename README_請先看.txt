多人棋牌館 V1.0.2 台灣麻將16張修正版

【本機測試】
1. 解壓縮
2. 雙擊 START_CARD_HALL.bat
3. 主控頁：http://localhost:3000/admin.html
4. 玩家頁：http://localhost:3000/player.html

【Render 部署】
此 ZIP 已附 render.yaml。
若你用 GitHub + Render：
1. 將整個專案內容上傳到 GitHub repository。
2. Render 建立 Web Service，連到該 repository。
3. Build Command：npm install
4. Start Command：npm start
5. 部署完成後：
   主控：https://你的網址/admin.html
   玩家：https://你的網址/player.html

【V1.0 功能】
- 五款遊戲：大老二、牌七、十三支、鬥地主、麻將
- 主控／玩家分離
- 多房間
- 6 位數房號
- 房間密碼可不設
- 同房玩家名稱不可重複
- 複製玩家網址、複製文字分享分開
- 文字分享會寫明 60 秒斷線重連
- 玩家重新整理頁面可用瀏覽器保存的重連 Token 回到原座位
- 滿員自動開始、開始倒數、出牌秒數、回合數、回合間隔、持續遊玩
- 勝場、回合結果、總排行榜
- 最近出牌紀錄
- 聲音開／關（撲克牌與麻將使用不同短音效）
- 取消選取
- 牌七無合法牌時必須選一張蓋牌
- 麻將牌面改為筒／索／萬與字牌圖像
- 手機版桌面棄牌縮小排列

【目前規則範圍】
- 大老二：可正式測多人流程。
- 牌七：可正式測多人流程，無牌可接時蓋牌。
- 十三支：目前先用一鍵自動排牌，手動拖曳排牌待後續升級。
- 鬥地主：目前支援單張、對子、三條、順子、炸彈；更多複合牌型待升級。
- 麻將：目前支援摸牌、打牌、自摸胡；吃、碰、槓待升級。

因此建議上線名稱可寫「V1.0 公開測試」，讓玩家先幫你測連線、房間與玩法流程。

【V1.0.1 修正】
- 重連 Token 改用 sessionStorage，每個分頁／視窗各自獨立，不再互搶座位。
- 同一分頁重新整理仍可回原座位。
- Socket 短暫斷線恢復後會自動重新加入原房間。

【V1.0.2 修正】
- 麻將改為台灣 16 張：平常 16 張，摸牌後 17 張再打出一張。
- 自摸胡判定改為 17 張、五組面子＋一對將。
- 修正牌牆摸完時應為流局，不再錯誤判定當前玩家獲勝。
- 1～9 筒改用固定麻將圖案排列，修正 5 筒圖案。

【V1.0.3 台灣麻將互動版】
- 台灣 16 張維持。
- 新增吃、碰、明槓、暗槓、胡、過。
- 新增副露區。
- 吃只限上家棄牌。
- 棄牌後有 5 秒反應時間；胡優先，其次碰/槓，再來吃。
- 麻將牌面沿用/靠近麻將 BINGO 的白牌、綠邊、傳統筒條萬視覺方向。

【V1.0.4 麻將牌面與出牌修正版】
- 麻將 34 種基本牌面已直接改用 BINGO V21.10 專案 public/mahjong/ 的同一套 SVG 素材，不是仿畫。
- 1~9萬、1~9筒、1~9條、東南西北、中發白全部沿用同一套原素材。
- 保留原素材授權說明於 public/mahjong-license/。
- 修正麻將牌點選後沒有明顯選取狀態。
- 修正麻將選牌/出牌操作，選取改用牌 ID，不再依畫面 index。
- 輪到自己時：點牌會上浮＋黃框；再按「打出選取牌」即可打出。
- 不是自己回合時，出牌按鈕會停用並提示。
- 手機版重新縮放與重疊排列，16/17 張盡量同一列看清；摸到的第 17 張會與前牌稍微分開。

【V1.0.5 手機牌面＋聲音修正版】
- 麻將手牌不再重疊。
- 電腦版完整橫排；手機版改成 9 欄自動換行，優先確保每張牌完整可辨識。
- 選牌只小幅上浮，不再放大到遮住其他牌。
- 倒數音改用單一持續 AudioContext，每一秒都會觸發；最後 3 秒音調更明顯。
- 自己回合最後 3 秒也會提示音。
- 麻將打牌新增牌名語音：例如「三萬、五筒、七條、東風、紅中、發財、白板」。
- 吃／碰／槓／胡也會播放短音效＋語音。
- 瀏覽器限制：第一次進頁面後需至少點一下頁面，音效才能被瀏覽器允許播放；之後倒數會連續出聲。

【V1.0.6 麻將白框修正版】
- 每一張麻將牌新增獨立白色牌身／白框。
- 加入圓角、細邊框、底部淡綠牌腳與陰影，讓每張牌看起來是完整麻將牌。
- 選牌時整張白色麻將牌一起上浮，不再只有圖案移動。
- 摸到的第 17 張仍保留額外區隔。
- 手機版白框會同步縮放，不影響牌面辨識。

【V1.1 五款遊戲公開測試版】
本版定位：先給主控本機測試，確認後部署到 Render，複製房間玩家網址給其他玩家實測。

這版重點：
1. 麻將：每一張實體麻將牌加入唯一 uid，同款牌可真正只選單張。
2. 麻將：吃／碰／槓／胡／過固定顯示；不能用時變灰，符合條件才亮起。
3. 麻將：保留 BINGO 原麻將素材、白色牌框、16 張台灣麻將、打牌語音與每秒倒數聲。
4. 鬥地主：改為 54 張（加入小王、大王），3 人各 17 張，地主再拿 3 張底牌；底牌顯示於桌面。
5. 鬥地主：加入王炸、炸彈、三帶一、三帶二、連對、無翅膀飛機等測試牌型。
6. 主控：關閉「滿員自動開始」時，房間卡會出現「▶ 開始遊戲」按鈕。
7. 重新整理／斷線：同一分頁若有保留 token，第一次 Socket 連線也會主動嘗試回到原座位。
8. 玩家名稱同房仍禁止重複；斷線座位保留 60 秒。

公開測試仍建議特別回報：
- 十三支目前仍是自動排牌測試流程，尚未做手動拖曳／倒水完整規則。
- 鬥地主目前地主由系統隨機，尚未做完整叫地主／搶地主流程。
- 台灣麻將尚未加入花牌與補花規則。
- 大老二順子 A／2 的地方規則仍需之後做主控可選。
